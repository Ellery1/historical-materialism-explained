# 《唯物主义历史观的基本阐述》写作规范

本skill适用于本书所有章节（含前言、结语、参考文献）的写作、修订与审查。当用户请求"补充某节内容"、"改写某段"、"加一个案例"、"加强逻辑链"等任何与本书正文相关的写作任务时，必须遵守以下规则。

## 一、预期读者画像

本书的目标读者是：**对中国近代史有基本了解的普通读者，对马克思主义哲学有一定兴趣但不是专业研究者**。

推论：
- **理论起点**：读者可能听说过"唯物史观""经济基础决定上层建筑"等概念，但不清楚其精确含义和论证逻辑
- **历史知识**：假设读者知道鸦片战争、法国大革命、十月革命等基本历史事件，但不知道具体的数据和细节——这些需要在正文中提供
- **数学要求**：不做数学假设。所有数据以表格和百分比呈现，不使用公式推导
- **知识盲区**：读者不清楚"社会存在""社会意识""生产关系""上层建筑"等术语的精确含义——首次出现必须用例子解释
- **反对"扣帽子"**：读者反感政治口号和空洞定性。所有论证必须基于事实、数据和逻辑

## 二、五大核心写作原则

### 原则1：数据-逻辑-结论（最重要）

本书不是宣传册，而是技术分析式的学术阐述。每一条重要论点必须走完整的"数据-逻辑-结论"链条：

1. **摆数据**：用具体的历史数据或经济数据作为起点（不是"我们认为"，而是"数据显示"）
2. **做推导**：从数据出发，逐步推导出结论（每一步都要有因果逻辑）
3. **给结论**：用简洁的语言总结

**反例（不可这样写）**：
> "英雄史观是错误的，因为它否认了人民群众的伟大作用。"

**正例**：
> "拿破仑远征俄国投入61万大军，6个月后仅剩约2万人。同一军事天才，奥斯特里茨胜利，俄国惨败。这说明决定战争胜负的并非个人意志，而是后勤、地理、兵力对比等客观物质条件。（霍布斯鲍姆《革命的年代》）"

### 原则2：对比说理，用数据击倒对手

本书的核心结构是"唯物史观 vs 其他历史观"的对比批判。对比时必须：

- 先准确陈述对方观点（引用其代表人物的原话）
- 再用数据反驳（不要只说"这是错误的"，要说"因为数据X/Y/Z与此矛盾"）
- 最后说明唯物史观如何更好地解释同一组数据

**格式示例**：
```
| 理论 | 对同一历史事件的解释 | 数据验证 |
|------|-------------------|---------|
| 英雄史观 | 拿破仑的军事天才决定了欧洲格局 | 同一拿破仑，奥斯特里茨胜、俄国惨败——个人相同，结果相反 |
| 地理决定论 | 热带使人懒惰 | 热带新加坡人均GDP约88000美元，热带刚果（金）约600美元 |
| 唯物史观 | 生产力发展和阶级力量对比决定战争胜负 | 俄国有本土防御优势、2亿人口、严寒天气——物质条件决定了侵略必败 |
```

### 原则3：每一论断必须有出处

任何具体数据和引用必须标注来源：

| 数据类型 | 出处要求 |
|---------|---------|
| 经典著作引文 | 标注到《马克思恩格斯选集》第X卷，人民出版社2012年版，第X页 |
| 经济史数据（人均GDP、产量等） | 标注作者、书名、出版社、年份 |
| 历史事实（伤亡人数、人口占比等） | 标注具体著作和页码 |
| 当代中国数据（GDP、贫困率等） | 标注《中国统计年鉴》年份，或世界银行等权威机构报告名称 |

**绝对禁止**：编造数据。AI写作时切勿虚构调查报告、精确页码或不存在的统计机构。如数据来源不确定，宁可不写也不要编造。

发现历史内容中存在来源可疑的数据时，应：
1. 删除或标注"⚠️ 此数据来源待核实"
2. 在 `待办事项.md` 中登记，写明位置和需要核实的内容

### 原则4：文字简洁，多用表格，少用长难句

- 能用表格对比的，不用段落叙述。本书大量使用 `| A | B | C |` 格式的表格
- 每个表格后面必须有数据分析段落，说明表格说明了什么规律或趋势
- 段落不宜超过5行，超过则考虑拆分或用列表
- 每个二级标题（##）下的内容，结构应一致：核心观点→数据支撑→逻辑推导

### 原则5：避免AI腔——少用破折号和"不是……而是……"

AI写作有两个常见的"语言指纹"，必须刻意避免：

**禁止1：滥用破折号（——）**

破折号在严肃学术文体中很少高频出现。AI生成的文本往往破折号密度过高。

| 反例 | 正例 |
|------|------|
| "经济基础是一个社会的骨骼——它决定社会面貌。" | "经济基础是一个社会的骨骼，它决定社会面貌。用逗号即可。" |
| "这组数据说明了问题——生产力才是最终决定力量。" | "这组数据说明：生产力才是最终决定力量。用冒号即可。" |

**规则**：一节文字中破折号不超过1个。能用逗号、句号、冒号替代的，一律不用破折号。

**禁止2：频繁使用"不是……而是……"句式**

"不是A，而是B"是AI最高频的写作模板之一。过度使用使文章显得套路化。

| 反例 | 正例 |
|------|------|
| "不是英雄创造历史，而是人民群众创造历史。" | "英雄史观把历史归结为个人意志。但数据显示：拿破仑同一个人，奥斯特里茨胜，俄国惨败。决定胜负的不是个人，是客观条件。"——用事实替代对立句 |
| "经济不是唯一的决定因素，而是最终的决定因素。" | "经济是'归根到底'的决定因素——恩格斯强调它不是唯一的。上层建筑同样起作用。"——换一种表达 |

**规则**：每节"不是……而是……"句式不超过1处。拿数据说话比拿句式对立更有说服力。

### 原则6：论证必须基于学术逻辑，不得以立场代替分析

本书的目标是用数据和逻辑证明唯物史观的解释力，而不是"宣布"它正确。以下三种写法严格禁止：

**禁止1：以"立场"或"阶级属性"作为批评理由**

| 反例 | 问题 | 正例 |
|------|------|------|
| "米涅仍是资产阶级立场，不能科学解释阶级斗争" | "资产阶级立场"不是学术错误——需要指出他具体哪里分析不到位 | "米涅看到了阶级斗争的存在，但没有追问：阶级为什么会形成？他把阶级的存在当作给定事实，没有从生产资料所有制中追溯阶级分化的经济根源" |
| "唯心史观为统治阶级服务" | 是否"为谁服务"不影响一个理论的学术对错 | 应从理论本身的解释力不足来批评，而非从它的政治功能 |

**禁止2：在没有充分论证的情况下预设唯物史观高于其他理论**

不能写"他们始终跨不过那道门槛"——这预设了唯物史观是"门槛之上"的终极真理。正确的做法是：展示唯物史观能解释哪些其他理论解释不了的事实，让读者自己判断哪个理论更有解释力。比较必须是平等的——用数据和案例说话，不用"高于""正确""科学"等预设性判断词。

**禁止3：用单一案例做"一句话"证明/证伪**

| 反例 | 问题 | 正例 |
|------|------|------|
| "拿破仑在奥斯特里茨胜、在俄国败，所以个人意志不决定历史" | 一个案例不能证明一条普遍规律。对手可以反驳：'也许俄国战役恰恰是拿破仑判断失误的证据，说明换一个更明智的人就不会失败' | 需要多组独立证据形成证据链：（1）拿破仑案例说明同一人的不同结果与客观条件相关；（2）科学发现的同时性说明"被发现"是必然的；（3）中国封建王朝的周期更替说明个人品行不能改变制度逻辑。三组独立证据指向同一结论，才构成有说服力的论证 |

**规则**：任何一个重要论点，至少需要两组以上独立证据支撑。单一案例只能作为"例证"而非"证明"。在比较不同理论时，必须从解释力（能解释多少事实、能做出什么可检验的预测）的角度比较，不得从"立场""阶级属性""进步性"等非学术维度评判。

### 原则7：理论观点必须配合历史语境和解释，不能做"语录摘抄"

本书不是马克思主义教材，不能只是转述"马克思说了什么"。每一个理论观点的呈现，都必须回答三个问题：

1. **什么问题促使他提出这个观点？**（历史语境：当时的社会现实、前人理论的不足）
2. **这个观点具体说了什么？**（用当时的历史事实来解释抽象命题的含义）
3. **它相比前人的分析推进了什么？**（从解释力的角度比较，而非从"正确/错误"的标签比较）

如果某个观点在当前章节只做简要提及、将在后续章节系统展开，则必须明确标注："此处仅做简要说明，第X章第X节将用数据系统验证这一命题。"

**反例**：
> "马克思提出：'不是意识决定生活，而是生活决定意识。'这是唯物史观的核心命题。"
>
> （问题：读者不知道这句话为什么重要、它映射到现实中是什么意思）

**正例**：
> "1840年代的英国工厂主们并不是先'想通了'才建工厂的，而是蒸汽机的发明使工厂生产比手工作坊利润更高，他们为了赚钱才建了工厂。工厂建起来之后，这些人的生活方式、价值观、政治诉求都跟着变了。他们开始要求议会席位、自由贸易、废除谷物法——这些'意识'的变化是'生活'变化的结果，不是原因。这就是'不是意识决定生活，而是生活决定意识'在19世纪英国的具体含义。"

### 原则8：抽象原理必须配合具体史料和数据实例

本书不允许出现"悬空"的抽象理论。每一条原理、每一个论断，都必须至少配一个具体的历史案例或经济数据来让读者理解"它在现实中是什么意思"。

**反例**：
> "生产力决定生产关系。"（然后就过去了，没有任何例子）

**正例**：
> "生产力决定生产关系。具体来说：当一个社会只有石器和采集狩猎的生产力水平时，一个人一天生产的食物只够自己吃，没有剩余。在这种条件下，私有制不可能产生（没有东西可以'私有'），阶级也不可能产生（没有剩余劳动可以被占有）。而当铁器和农业使一个人的产出超过自己的消耗时，剩余产品出现了，'谁来占有剩余'的问题才成为一个问题，私有制和阶级才随之产生。"

**最低要求**：每一个二级标题（##）下的论述，至少包含一个具体历史案例或一组数据。不允许整个二级标题下全是抽象理论而无一个实例。案例应尽量选取读者熟悉的历史事件（鸦片战争、法国大革命、工业革命、中国改革开放等），并提供可查证的数据（人口、GDP、产量、时间等）。

### 原则9：优先使用中国史料和数据

本书的目标读者是中国读者。在选择历史案例和数据时，优先选取中国历史中的材料（如秦统一六国、唐宋经济变革、明清资本主义萌芽、近代洋务运动、改革开放等），这样读者更有代入感。在中国案例不够充分的情况下再使用外国案例（如英国工业革命、法国大革命等）。

这不是排斥外国材料，而是优先序的问题：能用中国案例说清楚的就用中国案例，中国案例说不清楚或不够典型的再用外国案例。

### 原则10：正面论据与反例解释并重

在任何理论阐述中，不能只列举支持本方观点的证据，必须同时：

- 讨论明显的反例（如"德国经济落后但哲学领先"是对"经济决定文化"的挑战）
- 说明唯物史观如何解释这些反例（"社会意识有相对独立性"）
- 承认理论的边界和条件（"经济是最终的决定因素，不是唯一的决定因素"）

## 四、表格使用规范

本书以表格为骨架，务必遵循以下规则：

- **数据表格必须有表意明确的列标题**
- **对比类表格通常用"维度/指标 | 甲 | 乙 | 丙"的结构**
- **表格后必须紧跟数据分析**：不能放完表格就直接跳到下一个标题或下一节。至少用2-3句话说明"这个表格呈现了什么规律/趋势/对比，读者应该从中读出什么"。
- **表格中的数据超过3个数字的，必须标注来源**

**标准格式**：
```markdown
| 维度 | A | B | C |
|------|---|---|---|
| 指标1 | 100 | 200 | 300 |

（紧接2-3句分析：这个表格说明了什么规律/趋势，读者应读出什么）
```

## 五、术语统一规范

| 推荐用法 | 避免用法 | 原因 |
|---------|---------|------|
| 整体表述用"唯物史观" | 不统一使用"马克思主义历史观"/"历史唯物主义" | 全书统一，减少混淆 |
| 非科学历史观 | "错误的""腐朽的" | 技术分析语气，不扣帽子 |
| 亟待解决 | "必须立刻""刻不容缓" | 避免夸张语气 |
| 数据表明 | "充分证明""生动体现" | 去除宣传腔，用技术语言 |
| 根源于物质条件 | "说到底还是钱的问题" | 保持学术严肃性 |

## 六、引用规范

### 经典著作引用格式
```
马克思：《〈政治经济学批判〉序言》，《马克思恩格斯选集》第2卷，人民出版社2012年版，第2页。
```

### 学术著作引用格式
```
安格斯·麦迪森：《世界经济千年史》，伍晓鹰等译，北京大学出版社2003年版。
```

### 当代中国数据引用格式
```
国家统计局：《中国统计年鉴2024》，中国统计出版社2024年版。
世界银行：《世界发展指标2020》。
```

### 角标规范
- 正文引用时用 `[^1]` 格式的脚注
- 章末参考文献按正文中首次出现顺序编号
- 同一文献在全书多节引用时，每节独立重新编号

## 七、Git操作规范

- 所有git操作（commit、push、add等）必须经用户明确同意后才能执行
- 不要主动运行git commit，除非用户说"提交"或"推代码"
- HTML文件在markdown修改后重新生成，命名保持为`唯物主义历史观的基本阐述.html`

## 八、审查清单（修订章节时逐条对照）

修订任何章节时，完成修订后应逐条核对：

- [ ] 每个重要论断是否按"数据-逻辑-结论"链条展开？
- [ ] 对于本章涉及的"对立历史观"是否准确陈述了对方的核心主张？
- [ ] 所有数据是否有出处（文献参照/统计年鉴/权威著作）？
- [ ] 是否有编造数据或不可靠来源未标注？
- [ ] 是否讨论了可能的反例并给出解释？
- [ ] 是否有"充分证明""生动体现""腐朽""伟大"等宣传腔？
- [ ] 破折号是否每节不超过1个？"不是……而是……"句式是否每节不超过1处？
- [ ] 表格后是否有数据分析说明？（不能放完表格就跳到下一标题）
- [ ] 术语是否统一（唯物史观、经济基础等不混用）？
- [ ] 章节末尾是否有小结？
- [ ] 参考文献是否统一格式？

## 九、适用范围与例外

本规范适用于：
- 所有正文章节（第01-08章各节）
- 前言（00-前言.md）
- 结语（结语.md）
- 参考文献目录

例外：
- `build_book.py`、`待办事项.md` 等工程性文件不受本规范约束
- 需求文档.md、设计文档.md、大纲.md 属于项目规划文档，不受本规范约束
