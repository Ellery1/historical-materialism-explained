# 第一节 唯物史观：人民群众是历史的创造者

## 一、核心观点

"历史活动是群众的活动，随着历史活动的深入，必将是群众队伍的扩大。"[^1]——这是唯物史观关于历史创造者的核心命题。人民群众是社会物质财富、精神财富的创造者，是社会变革的决定力量。

## 二、概念界定：谁是"人民群众"？

"人民群众"是一个历史范畴——在不同历史时期有不同内涵，但有两个不变特征：（1）是社会成员的大多数；（2）是对社会进步起推动作用的人。

**主体**：在任何历史时期，劳动群众（从事物质和精神生产的劳动者）是人民群众的主体——因为他们是生产活动的最直接承担者。

## 三、论证：人民群众为什么是历史的创造者？

### （一）物质财富的创造者：一条无法绕过的逻辑

恩格斯在马克思墓前的讲话揭示了人类历史的一个基本事实："人们首先必须吃、喝、住、穿，然后才能从事政治、科学、艺术、宗教等等。"[^2]

**数据支撑**：

| 时间跨度 | 全球GDP增长 | 谁在生产？ |
|---------|-----------|----------|
| 公元1-1820年 | 从445增长到667（年增长率0.02%） | 农民、工匠——劳动群众 |
| 1820-2001年 | 从667增长到6049（年增长率1.2%） | 工人、工程师、科学家——劳动群众 |

全球GDP从公元1年到2001年增长了约13.6倍[^3]——这个数字背后，是两千年来数不尽的农民、工匠、工人、工程师日复一日的劳动积累。

**逻辑推导**：如果历史是由少数英雄创造的，那么在没有"英雄"的年代里，物质财富应该不增不减。但事实是，即便在"平庸"的太平年代，农业技术仍在改进，生产工具仍在改良，物质财富仍在缓慢但持续地增长——这是因为千千万万的劳动者在默默推动。

### （二）精神财富的创造者：实践是思想的源泉

**数据支撑**：民间创作是精英文化的基础

| 精英文化成果 | 民间文化来源 |
|------------|------------|
| 荷马史诗《伊利亚特》《奥德赛》 | 古代希腊民间口头传唱的英雄故事 |
| 中国《诗经》 | 305篇中约160篇"国风"直接来自民间歌谣 |
| 莎士比亚戏剧 | 大量情节取材于民间故事和传说 |
| 《水浒传》《西游记》 | 在民间话本、传说基础上整理创作 |

**逻辑推导**：杰出思想家、艺术家确实创作了伟大的精神产品，但他们的素材、灵感、语言，都是从人民群众的生活实践中来的。没有希腊民间关于特洛伊战争的口头传说，就没有荷马史诗；没有中国民间几百年流传的水浒故事，就没有施耐庵的《水浒传》。

### （三）社会变革的决定力量：用数据说话

**数据支撑一**：法国大革命（1789年）

法国大革命不是由几个启蒙思想家的著作引发的，而是第三等级（占人口98%）与特权等级之间的矛盾爆发的结果。[^4]

| 群体 | 革命中的作用 |
|------|-----------|
| 巴黎市民 | 1789年7月14日攻占巴士底狱——革命的实际引爆者 |
| 农民 | 1789年夏季"大恐慌"期间自发起义，摧毁封建庄园 |
| 无套裤汉（城市平民） | 1792年推翻君主制的主力 |

**数据支撑二**：淮海战役（1948-1949年）——"用小推车推出来的胜利"

| 项目 | 数字 |
|------|------|
| 支前民工 | 543万人 |
| 担架 | 20.6万副 |
| 大小车辆 | 88万辆 |
| 牲畜 | 76.7万头 |
| 运送粮食 | 4.34亿斤 |
| 船只 | 8500艘 |

[^5]

**逻辑推导**：543万支前民工——这个数字远远超过双方军队总人数（国民党约80万，解放军约60万）。没有这543万人推着小车、划着小船、扛着担架把粮食弹药送上前线，淮海战役就不可能打赢。陈毅说"淮海战役的胜利，是人民群众用小车推出来的"——这不是文学修辞，而是可量化的客观事实。

## 四、本节小结

唯物史观关于"人民群众是历史创造者"的命题，不是价值判断，而是可以验证的事实判断：

1. **物质生产**验证：全球GDP的每一分增长，都来自劳动者的双手。
2. **精神生产**验证：每一项精英文化成就，追根溯源都有民间基础。
3. **社会变革**验证：每一次重大革命的成功，都可以从参与群众的规模数据中找到解释——543万支前民工成就了淮海战役，98%的第三等级成就了法国大革命。
